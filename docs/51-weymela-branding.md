# Weymela branding

Weymela is the user-facing product name. The tagline is “ወይ መላ! — The smarter way to shop, promote, and earn.” Frontend values live in `src/CreatorPay.Web/src/brand.ts`. English is the default, Amharic is supported, currency is ETB, and support contact is a safe placeholder.

Internal projects, namespaces, database objects, telemetry, Docker images, solution files, and migration history remain named CreatorPay.
