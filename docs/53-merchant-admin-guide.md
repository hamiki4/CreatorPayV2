# Merchant Admin guide

The dashboard shows review, verification, trial, funding, wallet, location, and cashier status. Merchant Admins manage only their profile, locations, and staff. Contact changes restart verification. Logo support stores validated local metadata and does not require external storage.

Cashiers are invited with expiry, accept into a Cashier account, receive an assigned primary location, and never receive Merchant Admin permissions. They may be reassigned, revoked before acceptance, or disabled.
