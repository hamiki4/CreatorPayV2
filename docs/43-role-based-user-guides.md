# Pilot role guides

- Customer: register/sign in, complete mock phone verification when prompted, search or scan store QR, choose/save a creator, create a checkout QR, verify the cashier-entered amount, approve or reject, then monitor cashback and manual payouts.
- Cashier: sign in, verify assigned location, scan only the temporary checkout QR, enter bill total, compare the split preview, send once, and wait. If outcome is unknown, reload recent activity before retrying.
- Merchant admin: maintain profile/locations/cashiers, review creator requests, configure and monitor campaigns, choose one featured creator, display the discovery QR, watch trial/wallet funding, submit deposit evidence, and use transaction reports.
- Creator: maintain profile, find/request merchants, start approved campaigns, share campaign QR/deep link, monitor states/earnings/weekly payout and notifications. Customer identity is not exposed.
- Platform admin: approve merchants/trials, verify deposits, operate creator/customer manual payout states, support campaigns, review featured audits/fraud/disputes/reversals/recoveries, reconcile journals/revenue, and search audit logs. Direct balance editing is prohibited.
